# Code for genome skimming data processing, plastome phylogeny construction, SNP maximum-likelihood phylogeny construction, gene retrieval and coalescent ASTRAL phylogeny construction, ENMs for eastern and western Sarracenia alata populations using GBIF data

01 through 04 extract and prepare chloroplast data from raw genome-skims for maximum-likelihood phylogenetic inference

05 through 11 extract and prepare nuclear SNP data from raw genome-skims for maximum-likelihood phylogenetic inference

12 through 15 identifies and assembled BUSCO (Benchmarking Universal Single-Copy Orthologs) genes from raw genome-skims for coalescent phylogenetic inference

ENMs.R uses GBIF data to construct and evaluate environmental niche models for eastern and western lineages of Sarracenia alata, as well as conduct statistical comparisons on the best-constructed niche models
